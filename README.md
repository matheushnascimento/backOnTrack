# Back on Track - Documentação do Projeto

Aplicação React Native para registro de métricas pessoais mínimas. O MVP cobre 5 métricas: água, sono, alimentação, atividade física e estudo com autocuidado planejado como expansão pós-MVP.

## Documentos

1. [Project Charter](docs/01-project-charter.md) — visão, objetivo, justificativa, critérios de sucesso
2. [Escopo & MVP](docs/02-escopo-mvp.md) — modelo de domínio, o que entra na v1, non-goals
3. [Decisões Técnicas (ADR)](docs/03-decisoes-tecnicas.md) — stack escolhida e o porquê de cada decisão
4. [Roadmap de Milestones](docs/04-roadmap-milestones.md) — sequência de desenvolvimento (projeto em adaptação)

## Como usar esta documentação

Esses arquivos foram pensados pra viver dentro do repositório do projeto na pasta `docs/`. Conforme o projeto evolui, serão atualiados. Principalmente o ADR (toda decisão técnica nova vira uma entrada, e decisões revisadas mantêm o histórico dentro da própria entrada) e o roadmap marcando o que foi concluído, ajustando o que não fizer mais sentido.
